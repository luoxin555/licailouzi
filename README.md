## 五十四、实际入账真的入账 / 累计分红口径（v2026-11-20.54）

### 一、项目款项的「实际入账」现在真的进银行账户

原来只存了一个数、只改了显示，钱没动。现在：

- **填了就以它为准**：`实际入账 > 0` 时「已入账」直接取这个数（不再和明细比大小），「未入账 = 应收 − 实际入账」；
- **差额真的进账户**：保存时把「本次实际入账 − 上次实际入账」的差额记到你选的那个银行账户（`bank:<卡 id>` 只动那张卡），并在**收支记录**里留一条锁定记录「实际入账 · 项目名」；
- **不会重复入账**：一旦填了实际入账，二次入账的明细就只做记录、不再重复进现金（撤销明细同理）。

### 二、累计分红的口径

「总览 → 累计分红」= 持仓的分红（现金分红 + 红利再投资 + 送股折价）**＋ 对外投资的分红**（按各自记录的汇率折人民币）。对外投资的分红只做记录、不进总资产，但这一格必须算上它——否则记了分红还是 0。

实测（`r54.js`）：持仓 50 元 + 对外投资 100 元 → `dividendTotals().total = 150`，总览那一格显示 `¥150.00`；点开明细能看到「测试基金 50 / 项目A 100」两行。

**如果你那边还是 0**：先看弹窗标题里的版本号是不是 `v2026-11-20.54`——不是就是旧副本（Safari 缓存或旧文件）。用新文件覆盖后强制刷新一次即可。

## 五十五、应计利息两个数对不上 / 收支记录看详情（v2026-11-20.55）

### 一、总览 ¥75.21 vs 明细 ¥1,209.45

不是算错，是**两个口径**：总览那一格是「**到今天已经产生的利息**」（75.21），明细弹窗原来列的是「**到期总利息**」（1,209.45）。同一个名字两个数，当然对不上。

现在统一成一行两段：

> 招商银行 ｜ 已产生 ¥489.45 · 未产生 ¥720.00 ｜ **489.45**

- 「已产生」= 从起存日算到今天（提前支取按支取日 + 活期利率封顶）；
- 「未产生」= 到期总利息 − 已产生；
- **合计只算已产生**，所以明细合计 = 总览那格，一分不差。

### 二、收支记录每一行都能点开看详情

点整行弹出「收支详情」：方向（收入 / 支出）、金额、日期、账户（会自动翻成「招行 6225」这种具体卡名，没选账户就写「自动（现金 → 银行卡 → 微信 → 支付宝）」）、备注，以及来源。

- 自动生成的记录（借款、项目款项带出来的）标明「自动 · 自动生成」，**没有删除按钮**，只能回源头改；
- 手动记的仍有「删」。

## 五十七、删除借款后流水残留 / 余额对不上（v2026-11-20.57）

### 根因

借款类的收支流水是自动生成的（`locked: true`），但**删除来源记录时没人管它**：

1. `logCashFlow()` 写流水时 `ref.id` 恒为 `""`，流水根本不知道自己是哪条借款生的，事后无法定位；
2. 删除借出的按钮压根没有 `data-kind`，点了没反应；删除借入时又**反过来多记一条**「删除借入」，于是现金被扣了两次；
3. 结果：记录删了，流水还在，余额越删越偏。

### 改法

- `logCashFlow(kind, amount, account, date, note, refId)` 现在把来源 id 一起存进 `ref.id`；
- 新增 `removeCashFlows(kind, refId, name)`：按 `ref.kind + ref.id` 找出这条记录的全部自动流水，**逐条按反方向把现金退回**，再从 `cashLog` 里删掉；老数据没有 `ref.id` 时用备注前缀兜底；
- 删除确认弹窗改成「将删除「谁」，并一并撤掉它自动记的收支流水，现金按原路退回」；
- **不重复冲回**：撤流水时每条已经退过现金，所以只有一条流水都找不到（老数据）时才用本金兜底退一次；
- 借出卡片的编辑/删除按钮补上 `data-kind="loan"`，三类记录（借出 / 借入 / 项目款项）走同一套删除逻辑。

### 验证（`r57.js`，14 条全绿）

| 场景 | 断言 |
| --- | --- |
| 借出 1000 | 现金 −1000；生成 1 条锁定流水；`ref.id` = 借出记录 id |
| 删除借出 | 记录没了；流水没了；**现金回到放款前的原值** |
| 借入 2000 | 现金 +2000；流水方向为 `in` |
| 删除借入 | 记录没了；流水没了；现金回到原值（不再出现 −2000 的二次扣款） |

另含版本号与 div 配平检查。

**核对版本**：弹窗标题里的 `v2026-11-20.57`，以及 `sw.js` 的 `VERSION`。
